# ✨ Simple ChatBot

This is a simple chatbot web app built using **Streamlit** and **Google Generative AI (Gemini)**. It allows users to chat with an AI model and receive intelligent responses in real-time.

## 🚀 Features

- Conversational interface powered by Gemini 1.5 Flash
- Clean and minimal Streamlit UI
- Maintains chat history
- Styled message bubbles for user and bot

## 🛠️ Installation

1. **Clone the repository**
```bash
git clone https://github.com/yourusername/simple-chatbot.git
cd simple-chatbot
```

2. **Install the required packages**
```bash
pip install streamlit google-generativeai
```

3. **Set your API key**

Open the `app.py` file and replace the line:
```python
GOOGLE_API_KEY = "YOUR_API_KEY"
```
with your actual [Google Generative AI key](https://ai.google.dev/).

4. **Run the app**
```bash
streamlit run app.py
```

## 🔐 Requirements

- Python 3.8+
- A valid Google Generative AI API key
- Internet connection
